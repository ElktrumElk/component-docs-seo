# elk-components docs

> Documentation site for [elk-components](https://www.npmjs.com/package/elk-components) — a production-ready React animation, layout, and styling toolkit.

Built with [Next.js 16](https://nextjs.org) and [elk-components](https://component-docs-seo.vercel.app) itself.

## Stack

- **Framework:** Next.js 16.2 (App Router)
- **UI Library:** elk-components ^1.3.13
- **Styling:** Tailwind CSS 4
- **Language:** TypeScript
- **Analytics:** Vercel Analytics

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost](http://localhost).

## Build

```bash
pnpm build
pnpm start
```

## Structure

```
app/
  page.tsx          — Homepage (hero, features, quick start, icons showcase)
  layout.tsx        — Root layout (metadata, JSON-LD, Open Graph)
  globals.css       — Theme tokens, code syntax highlighting, utilities
  docs/
    layout.tsx      — Docs shell (sidebar + top bar)
    page.tsx        — Redirects /docs → /docs/overview
    [slug]/
      page.tsx      — Dynamic doc pages (44 component pages)
      not-found.tsx — Custom 404 for unknown slugs
components/
  docs/
    Sidebar.tsx     — Navigation sidebar with category groups
    DocsShell.tsx   — Client shell wrapper for docs layout
    pages/          — 46 individual component documentation pages
    shared/
      CodeBlock.tsx     — Plain-text code display block
      ComponentPage.tsx — Reusable page layout for component docs
      ExampleCard.tsx   — Interactive example wrapper
      PropsTable.tsx    — Component props reference table
public/
  llms.txt                         — AI-friendly site overview
  llms-full.txt                    — Full documentation dump for AI
  ai-rules.md                      — Strict usage rules for AI agents
  robots.txt                       — Generated by app/robots.ts
  sitemap.xml                      — Generated by app/sitemap.ts
  .well-known/agent-skills/        — AI agent skills definition
  og.png                           — Open Graph image
```

## AI / SEO Features

- `llms.txt` and `llms-full.txt` for AI crawler consumption
- `ai-rules.md` — strict rules ensuring AI agents use the correct `child` render-prop pattern
- `.well-known/agent-skills/index.json` — structured agent capabilities
- JSON-LD structured data (SoftwareSourceCode + FAQPage)
- robots.txt allowing all AI crawlers (GPTBot, ClaudeBot, Google-Extended)
- Sitemap with all 44 doc pages
- Semantic HTML (`<header>`, `<main>`, `<footer>`, `<article>`, `<section>`)
